# Care Plans, Explained Like a Friend Would

A walkthrough guide for nursing students. Education only — never medical advice.

> **Heads up first:** This guide teaches *how to write* a nursing care plan. It does not tell you what to do for any real patient. If you have questions about an actual patient, that is a conversation for your clinical instructor, your preceptor, and the care team — never a website. This guide contains no patient data, and you should not put any into it either.

**Start here: [00 - Read Me First](docs/00-read-me-first.md)**

## The five chapters

1. [00 - Read Me First](docs/00-read-me-first.md) — what a care plan actually is, and the ground rules
2. [01 - Assessment Cues](docs/01-assessment-cues.md) — collecting the raw material
3. [02 - NANDA-Style Language](docs/02-nanda-style-language.md) — turning cues into nursing diagnoses
4. [03 - Smart Goals](docs/03-smart-goals.md) — outcomes you can actually measure
5. [04 - Interventions](docs/04-interventions.md) — the "what we do about it" section
6. [05 - Evaluation](docs/05-evaluation.md) — did it work? say so, honestly
7. [06 - A Worked Example](docs/06-worked-example.md) — one sample plan, start to finish
8. [Appendix - Glossary & Cheat Sheet](docs/07-glossary-cheatsheet.md) — quick reference

## Blank worksheet

Print or fill in a blank care-plan worksheet: open `site/index.html` in any browser (no internet needed, no build step). There is an on-screen version and a print-friendly version at the bottom of the page.
